Power BI Dashboard Reproduction Guide
1. Run transform.py to generate clean_spotify.pkl.
2. Convert clean_spotify.pkl to CSV if needed using pandas:
      pd.read_pickle("clean_spotify.pkl").to_csv("SpotifyClean.csv", index=False)
3. Import SpotifyClean.csv into Power BI Desktop.
4. Create the following visuals:
   - Correlation heatmap for numeric features vs popularity
   - Scatter: tempo (x) vs popularity (y)
   - Scatter: duration_min (x) vs popularity (y)
   - Bar chart: average popularity by genre
   - Feature importance bar chart using feature_importance.pkl results
5. Add filters for:
   - genre
   - artist_name
   - release decade (create by extracting year from track_id if needed)
6. Save dashboard as SpotifyHitInsights.pbix.
